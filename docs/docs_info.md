# Docs

## Overview
The `docs` folder stores the architectural diagrams and design drafts for the SignVision project.

## Structure
*   `architecture.png`: A diagram explaining the workflow and system architecture (Frontend -> Backend -> Translators -> Database).
*   `draft.pdf`: A formal write-up, specification, or academic draft detailing the implementation or research foundation of SignVision.

## Purpose
Mainly used as references for developers, researchers, or anyone needing high-level conceptual understanding of the project layout.
