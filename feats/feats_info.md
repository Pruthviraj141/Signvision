# Feats

## Overview
The `feats` (likely short for "features" or "feature extraction") folder handles advanced NLP mappings or standalone algorithm logic outside the immediate running API.

## Structure
*   `Semantic-search/`: Represents logic or scripts used to establish semantic relationships between phrases. If a word isn't found exactly in the dictionary, semantic search acts as the fallback to find the closest sign equivalent.

## Connection
Provides utility algorithms (like creating embeddings) that are occasionally imported or executed manually to augment the `backend` capabilities.
